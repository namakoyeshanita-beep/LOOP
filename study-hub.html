Module library

Written by students who already did the module. Click "Past questions" to open the list.

Web Design

Coursework: Group project: plan a website, then build and host it.

Exam: Theory and short HTML and CSS questions.

Tip: Check your code with the W3C validator early.

Past questions
  1. Explain the difference between a class and an id in CSS.
  2. Write the HTML for a table with a header row.
  3. Name three ways of adding CSS to a web page.

Computer Architecture

Coursework: Group presentation and a short report.

Exam: Number systems, logic gates and the CPU.

Tip: Practise binary conversions until they are quick.

Past questions
  1. Explain the fetch, decode, execute cycle.
  2. Convert 156 to binary.
  3. Compare RISC and CISC processors.

Programming Fundamentals

Coursework: Group mini-system in Python with a viva.

Exam: Python basics on paper.

Tip: Be ready to explain every line of your code.

Past questions
  1. Write a program that turns a mark into a grade.
  2. Explain the difference between a list and a tuple.
  3. Use a loop to add the numbers 1 to 100.
